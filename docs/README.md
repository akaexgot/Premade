# Documentacion

Esta carpeta agrupa la documentacion del proyecto para mantener la raiz limpia.

## Carpetas

- `config/`: guias de configuracion del entorno, credenciales y servicios.
- `progress/`: checklists, resumenes por paso y estado de avance.
- `memoria/`: documentos de memoria del proyecto.

El `README.md` principal se mantiene en la raiz del repositorio.
