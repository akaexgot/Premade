# Base de datos

Archivos relacionados con Supabase/PostgreSQL.

## Contenido

- `schema.sql`: esquema principal de la base de datos.
- `queries.sql`: consultas utiles para pruebas y diagnostico.
- `SETUP_GUIDE.md`: guia de instalacion/configuracion de la BD.
- `fixes/`: scripts de correccion para RLS, chat, conversaciones y matching.
- `migrations/`: migraciones SQL auxiliares.
